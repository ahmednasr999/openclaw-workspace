# Daily Notes - 2026-08-05

## AnyDoc document parser pilot

- Benchmarked Firecrawl AnyDoc 0.1.6 against MarkItDown 0.1.5 on seven local samples across PDF, DOCX, PPTX, CSV, XLSX, and a scanned-PDF boundary case.
- AnyDoc retained all reference tokens on successful samples and was about 8 to 85 times faster. MarkItDown remained better for PowerPoint because it preserves explicit slide boundaries.
- Adopted a pinned hybrid router at `scripts/document-to-markdown.py`: AnyDoc for supported non-presentations, MarkItDown for presentations and fallback. The isolated runtime is `tools/document-parser-venv`.
- Integrated the router into Slides Lane source ingestion and updated slide QA commands.
- Verified zero parser network syscalls during local AnyDoc conversion, no known Python dependency vulnerabilities, explicit OCR-required failure for scanned PDFs, and successful end-to-end PPTX/DOCX ingestion.
- Evaluation report: `docs/architecture/anydoc-evaluation-2026-08-05.md`.
