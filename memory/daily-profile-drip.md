Rules:
- Ask one question per day maximum.
- Telegram DM only.
- No follow-up nag if Ahmed ignores it.
- Questions should come from gaps in existing files and improve executive positioning, job-search targeting, personal preferences, communication style, recurring decisions, or already-mentioned life context.
- Avoid random journaling and trivial personal questions.
- Raw answers can be appended here.
- Promote only durable, clear facts to USER.md or MEMORY.md, and only when appropriate.
