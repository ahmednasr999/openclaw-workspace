# Post-Change Verification

Use before saying gateway/runtime work is done.

1. Confirm gateway status or health.
2. Confirm the original requested behavior now works.
3. Confirm model/router state if model-sensitive.
4. Confirm no new warnings/errors were introduced.
5. Confirm any changed config path and whether restart/hot reload occurred.
6. State remaining risk or uncertainty.
7. If verification cannot be run, state exactly why.

Tool success alone is not completion.
