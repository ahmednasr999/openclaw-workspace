# Grounding checklist

- [ ] The symptom is observable and distinguishes this failure mode.
- [ ] The root cause is proven by current evidence or explicitly labeled as inference.
- [ ] The remedy was applied successfully to real state.
- [ ] Recovery checks test the outcome, not merely command exit status.
- [ ] Commands are safe, scoped, and include stop or rollback conditions when needed.
- [ ] Referenced paths, configuration keys, and source lines exist.
- [ ] Secrets, tokens, personal data, and hidden runtime instructions are absent.
- [ ] An overlap search found no better canonical document to update.
- [ ] Prevention addresses the cause rather than only the symptom.
