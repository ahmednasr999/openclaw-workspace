# Engagement Approval and Posting Checklist

Every answer must be **YES** before a comment is counted as posted. Any **NO** blocks the write path.

- [ ] Is the discovery/posting lane verified end-to-end to Windows Chrome, visibly authenticated as Ahmed, with no Ahmed-Mac, VPS-browser, cookie-based, or server-side authenticated fallback; if unavailable, was the run stopped rather than returning zero candidates?
- [ ] Is the target post still live and uniquely bound by activity URN, post URL, and author profile URL?
- [ ] Is the author outside the 14-day cooldown, and are duplicate candidates collapsed by activity URN plus author URL?
- [ ] Does the approval card contain the exact target identity and exact comment text Ahmed approved?
- [ ] Immediately before typing, do the visible account, post identity, author, and approved comment still match?
- [ ] After submission, does a fresh visible snapshot show Ahmed's exact comment on the intended post?
- [ ] Is the like state verified and the ontology `last_commented` update confirmed?
- [ ] Does the closeout count only unique comments with visible proof, excluding retries, stale approvals, skips, and failed proof captures?
