# Final Closeout Checklist

Report:

- Files changed.
- Tests/checks run with result.
- Autoreview command/result, selected model, or exact blocker if unavailable.
- Accepted findings fixed.
- Rejected/deferred findings with brief reasons.
- Plan deviations and their evidence-backed disposition.
- Scope check showing every changed file was authorized.
- Remaining risk or “none known”.

Do not claim done if the requested artifact/outcome was not inspected.
