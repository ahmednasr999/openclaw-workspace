# Metaphor Engine

## Start with verbs

Translate the thesis into a physical verb before choosing an object:

| Business mechanism | Physical verbs |
|---|---|
| unclear ownership | drop, bounce, wait, orphan, collide |
| hidden complexity | conceal, feed, route, support, converge |
| bottleneck | jam, choke, queue, squeeze, back up |
| decision latency | hold, stack, freeze, miss, expire |
| control enables speed | guide, rail, brake, channel, stabilize |
| fragmented system | split, mismatch, disconnect, drift |
| compounding value | stack, multiply, gear, amplify, harvest |
| leakage or waste | spill, drain, evaporate, loop, discard |
| dependency risk | balance, suspend, hinge, tether, prop up |
| sequence matters | unlock, assemble, stage, hand off, ignite |

The verb gives the illustration motion. A noun-only concept usually becomes an infographic.

## Scene families

Use scene families as starting points, not templates:

- backstage/frontstage cutaway
- machine with a visible jam or missing coupling
- relay or handoff with an orphaned object
- control room connected to a physical consequence
- counterweight, balance, or unstable support
- workshop tool used correctly or incorrectly
- logistics chute, conveyor, sorting gate, or loading bay
- bridge, lock, valve, track, or guardrail
- kitchen/service counter with hidden preparation lanes
- theater, airport, hospital flow, or marketplace only when the operating logic is specific and non-cliché

Vary scene, camera angle, central object, and action across recent posts. Reusing a toolbox, funnel, staircase, iceberg, domino chain, or gears too often creates a recognizable template even when each image is individually competent.

## Candidate test

For each candidate, complete this sentence:

`The reader sees [object] physically [verb], which maps to [business mechanism].`

If the sentence needs multiple “and then” clauses, the concept is too dense for one image.

## Executive oddness

Aim for controlled surprise: a familiar object performing an unexpected but logically exact action. The concept should be strange enough to stop the scroll, but sober enough for a GCC executive audience.

Avoid:

- cute characters or expressive mascots
- fantasy spectacle without business causality
- generic AI symbols
- literal collages of every topic keyword
- surrealism that requires the caption to decode
- copied motifs or layouts from reference examples

## Text-to-image separation

The image carries mechanism. Text carries only orientation:

- hook: the claim
- labels: element mapping
- accent annotation: the failure, path, or decision
- signature: Ahmed's brand

If labels are explaining full sentences, simplify the physical mapping.
