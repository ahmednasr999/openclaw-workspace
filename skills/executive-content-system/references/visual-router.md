# Visual Router

Use this guide when deciding what visual should accompany an executive LinkedIn post.

For every normal single-image route, first use `/root/.openclaw/workspace/skills/nasr-visual-metaphor/SKILL.md` to select one cognitive anchor, compare three physical metaphors, and build the 4:5 shot list. If one image cannot express the idea as one physical action, route it to a carousel.

## Premium statement card

Use when the post has one strong claim.

Pattern:
- 4:5 portrait by default
- warm off-white paper with black ink and restrained orange accents
- one clear handwritten headline
- compact system/toolkit metaphor tied to the post thesis
- Ahmed Nasr signature/footer
- no dense text, generic dark tech card, or stock-style background unless explicitly requested

## Metric card

Use when the post leads with a number.

Pattern:
- large number
- short interpretation
- source note if applicable
- restrained accent color

## Framework card

Use when the post has a model, checklist, maturity ladder, or governance system.

Pattern:
- 3-5 blocks max
- readable labels
- strong hierarchy
- no tiny captions

## Comparison card

Use when the post contrasts two models or decisions.

Pattern:
- split layout
- left/right contrast
- clear executive implication

## Carousel

Use when one image would be too dense.

Best for:
- 5-step frameworks
- transformation playbooks
- maturity models
- shift/risk/rule/action narratives

Default flow:
1. Hook
2. The shift
3. The risk
4. The operating rule
5. The practical action
6. Question or CTA

## Avoid

- borrowed mascots, copied creator compositions, or recently repeated dominant objects
- static icon collages without physical causality
- meaningless robots
- abstract neon geometry
- busy backgrounds behind text
- stock-photo handshakes
- hospital/fintech clichés unless grounded in the actual post
- text smaller than mobile-readable size
