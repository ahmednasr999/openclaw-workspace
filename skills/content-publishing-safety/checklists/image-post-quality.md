# Image Post Quality Checklist

Use before saying a premium LinkedIn visual is ready.

1. Candidate exists and opens.
2. Ratio is correct, default 9:16 unless requested otherwise.
3. Main headline is mobile-readable.
4. Support copy is short and readable.
5. Visual matches caption thesis.
6. Craft is comparable to the default reference.
7. Has cinematic depth, not flat wallpaper.
8. Has blue/gold execution/governance visual language.
9. Footer is polished and Ahmed-branded.
10. No copied old text, contamination, overlap, or dense labels.
11. Side-by-side comparison or equivalent inspection completed.

Fail fast if any item fails.
