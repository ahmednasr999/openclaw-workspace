# Post-Publish Verification Checklist

Use after publishing, scheduling, or retrying public content.

1. Confirm external action returned success.
2. Confirm live post or scheduled item exists when possible.
3. Confirm caption is complete and not truncated.
4. Confirm media is attached and rendered correctly.
5. Confirm no duplicate was created.
6. Record URL/id if available.
7. Update source status if that workflow requires it.
8. Report concise closeout with evidence and remaining risk.

API success alone is not proof of correct publication.
