## Acceptance Gate

- 30% or greater reduction in median active context across a comparable 20-session sample.
- All six low-risk cases pass before protected workflows are tested.
- All 14 high/critical cases pass before promotion.
- No new approval noise.
- No model switch.
- No regression in confidentiality, no-fabrication rules, external/public gates, duplicate prevention, or proof of delivery.
- Roll back any change after one critical failure or two repeated non-critical regressions.
