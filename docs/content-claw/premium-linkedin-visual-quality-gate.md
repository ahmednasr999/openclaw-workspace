## Required pass standard

A candidate passes only if both axes pass:

1. Format compliance
   - Warm off-white paper or comparable premium paper texture.
   - One dominant mobile-readable handwritten hook.
   - Compact flow, toolkit, system, or operating-model diagram.
   - Ahmed Nasr signature/footer.
   - No dense labels, tiny text, generic boxes, or visual clutter.

2. Premium craft parity
   - Feels as premium as the references, not merely similar.
   - Authentic black-ink linework, handwritten lettering, and restrained orange accents.
   - Clear execution/system metaphor tied to the post thesis.
   - Strong whitespace, balanced composition, footer polish, and mobile readability.

## Auto-rejects

Reject immediately if any are true:

- Old text contamination or text pasted over the reference.
- Generic stock/social-template look.
- Generic dark tech card, cinematic stock background, or blue/gold execution-card direction unless explicitly requested.
- Flat, cheap, or sketch-filter-like rendering.
- Multiple small panels competing with the hook.
- Weak footer or missing Ahmed signature/brand treatment.
- The candidate only passes because it was generated or sent successfully.

## Evidence required before saying done

- Candidate file path.
- Reference file path.
- Local inspection statement against both axes.
- Prefer a side-by-side comparison artifact when practical.
- If it fails, state the exact failure class and next iteration path.

## Ownership rule

NASR owns the final quality call. CMO can support generation/refinement, but repeated nudges or CMO claims are not completion evidence.
