# Premium LinkedIn visual quality gate

## Default reference

Use this reference for every Ahmed LinkedIn post visual unless Ahmed explicitly chooses another direction:

`/root/.openclaw/workspace/output/jobzoom-visuals/ahmed-linkedin-ai-execution-card-4k.jpg`

The reference is a quality target, not a canvas. Do not paste new text over the old design.

## Required pass standard

A candidate passes only if both axes pass:

1. Format compliance
   - 9:16 executive card.
   - One dominant mobile-readable hook.
   - One short support line.
   - Ahmed-branded footer.
   - No dense labels, tiny text, generic boxes, or infographic clutter.

2. Premium craft parity
   - Feels as premium as the reference, not merely similar.
   - Cinematic boardroom/city/execution atmosphere with depth.
   - Strong gold/white hierarchy with blue/gold accents.
   - Clear execution/system metaphor.
   - Clean typography, spacing, footer polish, and mobile readability.

## Auto-rejects

Reject immediately if any are true:

- Old text contamination or text pasted over the reference.
- Generic stock/social-template look.
- Flat wallpaper background without depth or executive atmosphere.
- Multiple small panels competing with the hook.
- Weak footer or missing Ahmed brand treatment.
- The candidate only passes because it was generated or sent successfully.

## Evidence required before saying done

- Candidate file path.
- Reference file path.
- Local inspection statement against both axes.
- Prefer a side-by-side comparison artifact when practical.
- If it fails, state the exact failure class and next iteration path.

## Ownership rule

NASR owns the final quality call. CMO can support generation/refinement, but repeated nudges or CMO claims are not completion evidence.
